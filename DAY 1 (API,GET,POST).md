## Weather URL breakdown
-**Endpoint:** https://api.open-meteo.com/v1/forecast`, which is _where_ you’re calling
- **Query parameters:** everything after the `?`, which is _what_ you’re asking for(`latitude=11.0`, `longitude=77.0`, `current_weather=true`), joined by `&`
